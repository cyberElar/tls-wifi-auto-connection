# 校园网自动登录（Windows）

装好以后，每次开机连上校园 Wi-Fi 就会自动完成认证，不用再打开网页输入账号密码。

适用于 Windows 10 / 11（64 位）。不需要安装 Python，也不用打开命令行。

## 安装（约 1 分钟）

1. 下载 **`CampusLoginSetup-v0.2.0-windows-x64.exe`**（只需要这一个文件）。
2. 双击运行。
   - 如果出现蓝色窗口“Windows 已保护你的电脑”：点 **更多信息** → **仍要运行**。
     这个程序没有购买代码签名证书，所以 Windows 会这样提示。
   - 出现“是否允许此应用对你的设备进行更改”时，点 **是**。
3. 填写 **校园账号** 和 **密码**。
   校园网络名称（`Tsinglan-School`）和 Wi-Fi 网卡一般会自动填好，不用改。
4. 点 **安装 / 更新并启用**。

安装完成后，可以点 **查看运行状态**，确认是否显示“已自动登录校园网”或“当前在线”。
下载的 exe 文件之后可以删除。

## 常见问题

**改了密码怎么办？**
重新运行安装程序，填写新密码，再点一次“安装 / 更新并启用”。

**提示登录失败？**
点“查看运行状态”。如果显示账号或密码错误，请重新安装并仔细填写。
程序在密码错误时会逐渐放慢重试，最多 10 分钟试一次，不会频繁尝试导致账号被锁。

**不在学校时会怎样？**
程序只在连接校园 Wi-Fi 时工作，在家或其他网络下什么都不做。

**提示找不到 Wi-Fi 网卡？**
在“Wi-Fi 网卡”下拉框里选择你正在使用的无线网卡（通常叫 `WLAN` 或 `Wi-Fi`）。

**遇到其他问题？**
点“查看运行状态”，把窗口截图发给维护者。

## 卸载

运行安装程序，点 **卸载**，再选择：

- **是**：停止自动登录，并删除保存的账号密码和日志（不再使用时选这个）；
- **否**：只停止自动登录，保留账号密码。

## 账号密码存在哪里

保存在 `C:\Program Files\CampusLogin\credentials.json`，只有系统和管理员可以读取。
密码没有加密，请不要在别人也有管理员权限的电脑上使用。

校园认证网页本身使用不加密的 HTTP，并且这个程序会在连上名为 `Tsinglan-School` 的
Wi-Fi 时自动提交账号密码。如果有人在附近开一个同名热点，就可能收到你的密码。
这是学校认证系统的设计，程序无法完全避免；看到可疑的同名 Wi-Fi 时请不要连接。

从 0.1.0 升级：直接运行新版安装程序即可。旧版保存在 `C:\ProgramData\CampusLogin` 的文件
会在安装成功后自动删除。

## 校验文件（可选）

每个版本都附带 `.sha256` 文件。需要确认下载完整时，在 PowerShell 中运行：

```powershell
Get-FileHash .\CampusLoginSetup-v0.2.0-windows-x64.exe -Algorithm SHA256
```

结果应与 `.sha256` 文件中的值一致。
